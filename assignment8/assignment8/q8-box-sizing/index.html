Box-Sizing Comparison

content-box

Width: 200px
Padding: 20px
Border: 5px

Rendered width = 200 + (20×2) + (5×2) = 250px

border-box

Width: 200px
Padding: 20px
Border: 5px

Rendered width = 200px (padding and border included)

By default, browsers use content-box, where padding and border are added on top of the specified width, making the element larger than intended. Setting box-sizing: border-box keeps the total width fixed by including padding and border inside that width, which makes layouts far more predictable.
