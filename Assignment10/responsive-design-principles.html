Core Principles of Responsive Design

Fluid Layouts

Widths use relative units so containers grow and shrink with the viewport.

.container { width: 100%; max-width: 1200px; }

Flexible Media

Images and media resize automatically to fit their container.

img { max-width: 100%; height: auto; }

Breakpoints

Media queries apply different styles at specific viewport widths.

@media (max-width: 600px) { ... }
