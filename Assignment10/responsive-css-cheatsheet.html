Responsive CSS Cheat Sheet

Filters

filter: blur(5px), grayscale(100%), sepia(100%) apply visual effects to images.

Media Queries

@media (max-width: 600px) { ... } applies styles only below a given width.

Responsive Design

Layouts adapt fluidly to different screen sizes using Flexbox and Grid.

Typography

clamp(1rem, 2vw, 1.5rem) scales font size smoothly between limits.

Flexbox

display: flex arranges items in a row or column with flexible sizing.

Grid

display: grid with grid-template-columns builds two-dimensional layouts.
